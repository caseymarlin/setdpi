# SetDPI - Free Online Image DPI Changer

Change the DPI of any image instantly in your browser. No uploads, no installs.

**[Try it now at setdpi.com](https://setdpi.com)**

## Features

- Change DPI of PNG, JPEG, TIFF, BMP, and WebP images
- 100% browser-based — your images never leave your computer
- No file size limits
- Batch processing — change DPI of multiple images at once
- Download individually or as a ZIP file
- No quality loss — lossless DPI metadata update

## How It Works

DPI (dots per inch) is metadata stored in image files that tells printers and displays the intended physical size. SetDPI modifies this metadata without recompressing or altering the actual image pixels.

## Common Use Cases

- Preparing images for print (300 DPI standard)
- Fixing DPI for document submission requirements
- Adjusting images for specific display resolutions
- Batch updating DPI across multiple files

## Privacy

All processing happens locally in your browser. No images are uploaded to any server.
